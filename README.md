<h1 align="center">Summarist</h1>

Summarist is a book database website mockup that allows users to find books and listen to summaries. 


<h2 align="center">Stack Used</h2>
*Next.js <br/>
*TypeScript <br/>
*CSS<br/>
*HTML<br/>
*Redux<br/>
*Firebase<br/>
*Stripe

<h2 align="center">Main Features</h2>
*Modal for logging in or creating a new account<br/>
*Interactive Search Bar to search for books<br/>
*Audio Player to listen to the book summary<br/>
*Ability to upgrade your account using Stripe for the payment

<h2 align="center">My Conributions</h2>
This was the culmination of my Advanced Virtual Internship with Frontend Simplified. I was given a website and I needed to copy the UI design and functionality. <br/>
Here is what I contributed to the project:<br/>

*Added Skeleton Loading States<br/>
*Used Firebase to create and maintain a database of Users and Account Types<br/>
*Implemented an audio bar that played the audio summary of the chosen book<br/>
*Rerouted users who wanted to upgrade their subscription to a payment page using Stripe
